# Roadmap (RU)

> Английская версия: [ROADMAP.md](ROADMAP.md). При расхождениях приоритет у английской версии.

Куда движется Aspid.FastTools после 1.0: темы по порядку, без дат.

## 1.1

### Читаемые инспекторы SerializeReference

Полиморфное поле или список должны показывать, что внутри, не раскрывая каждый элемент: однострочная сводка
свёрнутого экземпляра, цвет-акцент для каждого типа и тип на элементе списка, пока его перетаскивают.

[#155](https://github.com/VPDPersonal/Aspid.FastTools/issues/155),
[#156](https://github.com/VPDPersonal/Aspid.FastTools/issues/156),
[#160](https://github.com/VPDPersonal/Aspid.FastTools/issues/160)

### TypeSelector предлагает нужные типы

Новый элемент списка или пустое поле получают разумный тип по умолчанию вместо пустоты, а в пикере не видно лишнего:
исключённых типов, чужих сборок и пространств имён, типов с `[Obsolete]` и всего, что отсекает собственное правило.

[#154](https://github.com/VPDPersonal/Aspid.FastTools/issues/154),
[#157](https://github.com/VPDPersonal/Aspid.FastTools/issues/157)

### Данные SerializeReference переживают изменения

Шаблоны сохраняют вложенных `[SerializeReference]`-детей, скопированное значение переживает перезапуск редактора,
а тип, у которого поменялись поля, может обновить старые ассеты, а не потерять их данные.

[#158](https://github.com/VPDPersonal/Aspid.FastTools/issues/158),
[#159](https://github.com/VPDPersonal/Aspid.FastTools/issues/159),
[#162](https://github.com/VPDPersonal/Aspid.FastTools/issues/162)

### Типы по имени в рантайме

Рантайм-API, который превращает имя типа в `Type` и экземпляр, — для модов и data-driven контента; сейчас всё это
есть только в редакторе.

[#161](https://github.com/VPDPersonal/Aspid.FastTools/issues/161)

### Маркеры по категориям

Маркеры попадают в категории профилировщика — AI, Physics, Rendering и другие: Timeline красит их по категории, а фильтр
прячет то, что сейчас не нужно. Категория задаётся для одного вызова или сразу для всего типа.

### Быстрые исправления предупреждений

У каждого предупреждения FastTools в Rider и Visual Studio есть исправление в один клик: `using` для scope маркера,
который никогда не закрывается, удаление `Allow`, который не действует на managed reference. Так же выделенный код
оборачивается в маркер.

## Позже

### EnumValues переживают переименование enum

Строки хранятся по имени члена, поэтому после переименования строка теряется. `[FormerlySerializedAs]` на
переименованном члене переносит её, а проверка проекта показывает все таблицы с потерянными ключами ещё до сборки.

### Маркеры везде

Маркеры в статических методах и классах, где сейчас нет `this`; значение в сэмпле — например, сколько агентов обработал
шаг; и время маркера в билде игрока — для оверлея на экране или теста производительности.

### Меньше шаблонного кода от генераторов

Сгенерированный код для того, что в каждом проекте пишут руками: поле, которое само добавляет `[RequireComponent]`,
и обработчики событий UI Toolkit, привязанные по имени элемента.

[#1](https://github.com/VPDPersonal/Aspid.FastTools/issues/1),
[#3](https://github.com/VPDPersonal/Aspid.FastTools/issues/3),
[#4](https://github.com/VPDPersonal/Aspid.FastTools/issues/4)
