# Namespace Aspid.FastTools.Ids {#Aspid_FastTools_Ids}

### Namespaces

 [Aspid.FastTools.Ids.Editors](Aspid.FastTools.Ids.Editors.md)

### Classes

 [IdRegistry\<T\>](Aspid.FastTools.Ids.IdRegistry-1.md)

A strongly typed wrapper around [`IdRegistry`](Aspid.FastTools.Ids.IdRegistry.md) that exposes [`IId`](Aspid.FastTools.Ids.IId.md)-aware membership checks.

 [IdRegistry](Aspid.FastTools.Ids.IdRegistry.md)

A ScriptableObject that maps string names to stable integer IDs for a given struct type.

 [UniqueIdAttribute](Aspid.FastTools.Ids.UniqueIdAttribute.md)

Marks an integer field as a project-wide unique id. The editor drawer enforces uniqueness across all
fields decorated with this attribute and offers a registry-aware id picker.
The attribute is editor-only — its [`ConditionalAttribute`](https://learn.microsoft.com/dotnet/api/system.diagnostics.conditionalattribute) ensures usages are stripped from player builds.

### Interfaces

 [IId](Aspid.FastTools.Ids.IId.md)

Contract for id structs generated by <code>IdStructGenerator</code> and consumed by
[`IdRegistry<T>`](Aspid.FastTools.Ids.IdRegistry-1.md).
Each implementing struct is bound to exactly one registry asset.
